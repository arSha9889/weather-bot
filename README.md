# Telegram-бот погоды на Go

Бот показывает текущую погоду по команде `/weather Город`. Использует [OpenWeatherMap API](https://openweathermap.org/api) и библиотеку [go-telegram/bot](https://github.com/go-telegram/bot).

## Требования

- Go 1.21+
- Токен бота от [@BotFather](https://t.me/BotFather)
- Доступ в интернет (OpenWeatherMap API)

## Установка и запуск

1. Клонируйте или скопируйте проект, перейдите в каталог:

   ```bash
   cd "weather bot на Go"
   ```

2. Установите зависимости:

   ```bash
   go mod tidy
   ```

3. Задайте переменную окружения с токеном бота:

   ```bash
   export BOT_TOKEN=ваш_токен_от_BotFather
   ```

   Либо создайте файл `.env` (см. `.env.example`) и загружайте его через `source .env` или любой менеджер env — в коде используется только `os.Getenv("BOT_TOKEN")`.

4. Запустите бота:

   ```bash
   go run main.go
   ```

## Использование

- **Команда:** `/weather Город`  
  Примеры: `/weather Москва`, `/weather London`, `/weather Санкт-Петербург`

- В ответ бот пришлёт:
  - город и страну;
  - температуру (°C);
  - «ощущается как» (°C);
  - влажность (%);
  - ветер (м/с);
  - описание погоды с эмодзи (☀️, ☁️, 🌧, ❄️ и др.).

- Если город не найден, бот отправит понятное сообщение с подсказкой.

## Структура проекта

- `main.go` — точка входа, обработка команд Telegram и запросы к OpenWeatherMap.
- `go.mod` — модуль Go и зависимость `github.com/go-telegram/bot`.
- `.env.example` — пример переменных окружения (токен бота).
- `README.md` — эта инструкция.

## Конфигурация

| Переменная   | Описание                |
|-------------|-------------------------|
| `BOT_TOKEN` | Токен бота от BotFather |

Ключ OpenWeatherMap встроен в код (константа в `main.go`). При необходимости его можно вынести в переменную окружения и читать через `os.Getenv("OPENWEATHER_API_KEY")`.
